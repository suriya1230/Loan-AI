#  Loan-AI — Intelligent Loan Approval System

Loan-AI is an AI-powered web application that predicts loan approval decisions instantly using machine learning. It provides explainable results and personalized recommendations to help users understand their eligibility.

This project combines **machine learning**, **explainable AI**, and a modern **React frontend** to create a transparent and user-friendly loan evaluation platform.

---

##  Features

-  Instant loan approval prediction
-  Explainable AI using SHAP & LIME
-  Transparent decision reasoning
-  Personalized eligibility recommendations
-  Modern React user interface
-  Secure backend processing

---

##  Tech Stack

### Backend
- Python
- Flask API
- Scikit-learn
- SHAP & LIME (Explainability)

### Frontend
- React.js
- Tailwind CSS
- Framer Motion

### Deployment Ready
- Docker support
- AWS / Cloud compatible
